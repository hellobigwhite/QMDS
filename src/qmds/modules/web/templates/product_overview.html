数据库结构说明

URL来源数据库
qmds_url_stores - 存储店铺URL数据
URL来源集合
{category}__{subcategory} - 存储已筛选的店铺URL（filter_status/crawl_status 字段区分状态）；{category} 集合存储未筛选URL
产品数据数据库
qmds_product_data - 存储商品数据
产品数据集合
{category}__{subcategory} - 单一集合，用 clean_status/export_status 字段区分状态
分类命名规则
一级分类与二级分类用双下划线 __ 分隔，无二级分类时使用 other
清洗状态字段
clean_status - unclean（未清洗）、cleaned（已清洗）、failed（清洗失败）
导出状态字段
export_status - unexported（未导出）、exported（已导出）
数据爬取流程
从 {category}__{subcategory} 获取 filter_status=filtered 且 crawl_status=uncrawled 的URL -> 爬取 /products.json -> 保存到 {category}__{subcategory}（clean_status=unclean）
数据清洗流程
从 {category}__{subcategory} 读取 clean_status=unclean 数据 -> 过滤 -> 更新 clean_status=cleaned/failed（同集合）
