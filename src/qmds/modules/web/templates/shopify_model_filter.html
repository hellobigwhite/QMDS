📋 功能说明

🤖 AI 智能分类流程（在 cc_c.shopify_site 上操作）

  1. 阶段1 - 抓取网站信息：查询 page_info 为空且无 category/subcategory 的记录，并发抓取首页 HTML 和 /collections.json，提取结构化信息写回 page_info 字段
  2. 阶段2 - LLM 分类：读取已抓取 page_info 的记录，调用 MiMo 模型分类，将结果写回源文档：
    • 正常分类：写入 category（Google 名称）+ subcategory（完整路径），ai_status=classified
    • 非英文站：ai_status=non_english，记录 ai_language
    • 黑五类：ai_status=black_five，记录 ai_black_five_type
    • 综合站：ai_status=comprehensive，记录 ai_subcategories 列表
    • 无法识别：ai_status=unrecognized
  3. 直接导入：AI 分类完成后，运行下方导入，按 category/subcategory 字段导入到 {category}__{subcategory} 集合

📥 直接导入数据流程

  1. 查询源集合中 category 字段匹配且 extracted != true 的文档
  2. 解析 subcategory 字段（Google Taxonomy 路径格式）的最后一段作为二级分类
    例如: Hardware > Tools -> 二级分类 tools； Hardware > Tools > Hammers -> 二级分类 hammers
  3. 从 final_url 提取 scheme://netloc 作为 store_url
  4. 写入目标集合 {category}__{subcategory}（upsert，按 domain 去重，设置 filter_status=filtered）
  5. 更新源文档：extracted=true、extracted_at=时间戳、extracted_to=目标集合名

幂等性 & 重复保护

  • AI 抓取：只处理 page_info 为空的记录，已抓取的不会重复处理
  • AI 分类：只处理已抓取但未分类（ai_status 为空/pending）的记录，已分类的不会重复处理
  • 直接导入：源文档提取后标记 extracted=true，再次运行不会重复提取
  • 任务支持停止：在任务页面可中断
